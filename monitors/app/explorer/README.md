# App Capture Explorer

Small Express app for inspecting JSON capture files produced by the app monitor.

The selected file is read in the browser and posted to the server as JSON text. The server parses it in memory and does not save the file to disk.

## Install

```bash
cd monitors/app/explorer
npm install
```

## Run

```bash
npm start
```

Open:

```text
http://localhost:3499
```

Choose a generated capture file such as `vscode-traffic.json` or `app-traffic-20260516-120000.json`. Entries are rendered as collapsible rows with request payload, response payload, and headers.

## Notes

- Expected input is a JSON array generated by `monitors/app/capture.sh`.
- Files larger than 50 MB are rejected.
- Capture files can contain secrets in request headers and bodies.
